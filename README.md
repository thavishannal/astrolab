# Third-Year Astrolab Project
## On Calibrating the Period-Luminosity Relationship of Classical Cepheids
My third-year lab project, in which I constructed a data reduction pipeline that could calibrate the Cepheid Period-Luminosity relationship when given sparse data. Together with my lab partner, I observed 19 target stars over an extended period using Durham University's DRACO 2 telescope. We constructed an empirical light-curve model to independently measure the magnitude and period of individual Cepheids.
